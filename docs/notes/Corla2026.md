The list of what we hope to accomplish in this audit is a combination of doing what we did before better and adding some additional observation capabilities:
Fix the problem of ballot ordering, in which the order in which the ballots were pulled from storage did not match the order in which CORLA presented the ballots for auditing.  I have analyzed the process of ballot ordering and I believe I understand what happened.  See this document for what I think happened and how to fix it.
The observers from the League of Women Voters had several suggestions for how the observation process could have worked better for them. Most of them pertain to training and documentation that we are responsible for, but some are relevant to county procedures:
The observers were somewhat surprised by having to spend the first hour watching the process of breaking seals, ballots being pulled from the storage boxes, filling out forms, etc. I should have expected this, but I wasn't thinking about how the process would be different when canvass board members also serve as audit boards, so I didn't set the observers' expectations correctly. However, I think that learning about the process of pulling the ballots is something that observers should be able to do (optionally). I would like to be able to tell the observers that if they want to observe this process, they should arrive about ten minutes before the audit start time, and if they don't, they could arrive somewhat later, say, 30 minutes after the start time. It would be great if the two of you could explain the process as you go, ideally starting from the unsealing of the ballot boxes (if that's reasonable). I don't want to slow down the process, so you can let me know how that might work best for you. And regardless of whether any of the observers want to watch the process, *I* do. I want to understand more about how it works so I can make more educated recommendations as to how observers could participate.
All of the observers commented to me that the audit board members didn’t follow a particular pattern of reading votes. The auditors rarely named the contest, but only the voted-for choice. Sometimes they did name the contest, but in the reverse order, as in “No vote for Attorney General” instead of saying “Attorney General - blank”. I have been reluctant to suggest changes in county procedures, but since every one of the observers mentioned this, and this might be a way to improve the way that audit board members understand each other, you might want to suggest a clear and consistent pattern for the way that audit board members read out the votes.
The process by which we got a redacted CVR worked very well in La Plata last time (thanks, Arielle!). We'd like to do that again. We will provide a new version of the redaction program, but I don't think that you will see a difference. At some point fairly soon (well before the 11/13 deadline for uploading the CVR to the state), I'd like to send you the new version of the program and have you test it on the unredacted CVR from an earlier election, such as the June primary, just because we'd like to know as soon as possible if there are any problems. I hope that that will be fairly easy. Let me know if that's possible and when a good time for that would be.
I'm still working this out, but I might want the redacted CVR, the ballot manifest, and the list of ballots to be audited to be supplied on your website, in a format that I will specify. The informal way that you provided that information before was okay, and I can still work with it, but I'd like to move closer to the way that we want this data provided when this becomes more of an official process. I will send a description of that format to Arielle later. I don't think it will be very difficult to do, but if it can't be done, no problem.  
One of the changes we're making for observers is to provide a way for them to verify votes using a laptop computer, a tablet, or even a smartphone in order to see the ballot contents. I don't think that this will have any impact on the county except that the observers might need wi-fi.
At the pilot in July, you did as we had requested and allowed observers and audit board members to have some additional ballots pulled and verified at the end of the official RLA. I loved how that ended up working! I hope it seemed like a good thing to you too. Now I can see how observers who are dubious about the whole vote-counting process would be impressed by being able to select ballots randomly, on the fly, and be told by someone armed with the CVR file (as I was) exactly how that ballot was voted. I would like to do something similar at the Nov. pilot. I suggest the following, but please let me know if you think it should work differently or if this is too much:
I would like each of the observers to select five ballots before the audit and send me the imprintedIds (I'll work out how to do that, no involvement from you is necessary). I will bring a list of those ImprintedIds (on paper) to the audit.
I will supply the observers with a list of how those ballots were voted, based on the CVR.

After the official RLA is complete, the audit board members will read out the 15 or 20 ballots that were selected by the observers and the observers can compare the votes to the lists they have.
Then, I'd like observers and audit board members to be able to select some ballots directly from the boxes (with only staff and audit board members allowed to touch the ballots of course). Just one or two each (you can decide how many you want to allow). I'll be there with my computer program that looks up ballots in the CVR and we can verify that each of those ballots was correctly scanned, like we did in July.
Assuming the broad outline of this plan is acceptable, I will attend your RLA, doing more or less what I did before. Is it likely that the RLA will be on Nov 17 (the day after the dice roll)?
